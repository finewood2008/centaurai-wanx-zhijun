# 知君 · 独立桌面端

知君是独立 Electron 应用，连接本机 WANX（默认 `127.0.0.1:8088`）的原生运行与记忆能力，用万象账号登录。每个账号拥有一份知君个人主档案；首次进入由本人点击「创建我的知君档案」，从空白开始积累。再次进入恢复同一份档案。

登录页可切换到「注册」，无需邀请码，创建两款应用通用的普通账号。注册复用平台密码规则与登录验证，不自动创建任何 Agent 或档案；成功进入后仍由本人单独创建空白知君档案。提交后连接中断时显示结果未确认，可返回登录尝试恢复。

知君与万象的对话、记忆和资料在服务端按应用域隔离，不列举或绑定万象已有的 Agent，不迁移老知君数据。旧版万象登录会话与绑定会被清理，需要重新登录知君；原万象 Agent 和记忆保留。

界面保留纸、墨、朱砂的书房气质，以交谈为主。「对话」管理主题会话；「记忆」保留用户画像、记忆树、情绪日记和记忆沉淀，用户画像分为个人本体与记忆资料；「知识库」管理资料和深入理解；「设置」管理账号、微信与陪伴节奏。个人本体先显示雷达，本人确认后才进入核心理解；小机器人回响承接候选核对和资料讨论。

对话可选择多个文件，逐个展示上传结果，失败的文件由本人重试或移除；也可只发送文件。知君通过本地提取工具查阅正文，历史文件从专用来源接口打开。切换会话或账号会清除待发送文件，恢复连接不会自动重发。

「知识库」可创建多份独立私有资料库、上传文件并查看原生整理状态。新库按相关性参与交谈；本地模型或图片识字未就绪时显示实际状态，不提供远程处理回退。上传完成与可供检索分别展示，失败可重试整理。「围绕资料聊」只准备可编辑草稿；资料内容不自动视为本人的经历、观点或已确认记忆。回答中的记忆、上传文件与资料库来源仅来自成功的原生工具结果，绑定到实际查阅它们的回答。

客户端使用 `application_id: zhijun` 登录，并验证 `/auth/me` 的应用身份；`GET/POST /api/zhijun/profile` 读取、幂等创建或恢复个人主档案。未单独指定模型时使用平台默认模型；平台无可用模型或运行失败时显示真实状态，不会自动新建第二份档案。记忆写入操作只使用原生修正、弃用、采纳和拒绝接口，并重新读取结果。

## 开发

这是 WANX 仓库中的独立前端，复用 `../dashboard/src/api` 和原生聊天恢复协议。先按[根目录说明](../README.md)取得授权的 WANX SDK 安装包并安装 dashboard 依赖，再在本目录运行 `npm install`。SDK 二进制不在公开源码仓库中。

```sh
npm run build
npm test
npm start
```

启动开发应用需要官方 Electron 37.10.3 的完整运行时。可通过 `ZHIJUN_WANX_URL` 指定另一个本机 WANX HTTP 端口；客户端只接受 loopback。`ZHIJUN_UI_PORT`、`ZHIJUN_USER_DATA` 用于隔离测试，不是新记忆配置。

## macOS 交付

```sh
npm run build
ZHIJUN_ELECTRON_DIST=/path/to/electron/dist npm run package:mac
```

运行时目录应包含官方 `Electron.app`。脚本仅支持 Apple Silicon，复制前端和桌面壳，使用原知君图标，执行本地 ad-hoc 签名及校验；未公证。已有 `release/知君.app` 时先保留上一版再打包，脚本不会覆盖它。

构建检查包括 TypeScript 与 Vite；测试覆盖首次创建、旧登录清理、失败恢复、日期筛选、来源绑定、原生记忆操作、文件上传失败与切换隔离、资料库真实状态及桌面代理。macOS 包目标为 `release/知君.app`，实际交付以打包及应用验收结果为准。

产品边界与验收见 [交付说明](../docs/zhijun-agent-v1.md)。
