# 交流方式（开发中，尚未发布）

设置 → 交流方式。以当前登录身份、所选专家和角色为范围，在万象私人专家上保存。
四种预设：自然交流、温和倾听、直接建议、启发探索；五项微调：回复详略、表达语气、追问方式、建议主动程度、表达不同意见。
未设置时沿用专家原有方式。选择、微调或恢复都先改变草稿，点击保存才生效；保存后下一轮使用新偏好。新角色不继承其他角色的偏好。

## 双端协议

客户端网关 `GET /api/interaction-preferences` 返回 `{supported, preferences}`。
`PUT` 接受完整 v1 偏好，`DELETE` 恢复原有方式。身份与角色沿用网关现有校验；不接受 agent_id、as_user、提示词或模型参数。
网关只转发当前私人角色至万象 `/api/agents/{agent_id}/interaction-preferences`，万象响应 `{preferences}`。

```json
{"version":1,"preset":"natural","verbosity":"balanced","tone":"natural","questions":"necessary","advice":"situational","disagreement":"clear"}
```

完整枚举及预设见 `server/interaction-schema.mjs`；服务端对应 `octop.infra.agents.settings.interaction.InteractionPreferences`。
未知版本、字段和枚举均拒绝。缺少万象接口（404/405/501）时 UI 禁用保存；网络故障和权限错误不视为不支持。

万象保存到专家 `config_json.interaction_preferences`，公共模型调用中间件追加表达偏好，客户端和微信共用。它不改变 temperature、top_p、max_tokens，不改用户消息、不写用户记忆，也不替换系统提示词或角色文件。
原有 MBTI 配置保留；重叠的表达偏好按用户新选择执行，重置后恢复原行为。
忙碌返回 409；保存期间保留调用屏障，重载成功后才返回成功。重载失败回滚偏好字段，并恢复原运行时。客户端保留草稿供重试。

## 验证

客户端检查：`npm test`、`npm run test:ui`、`npm --prefix desktop test`、`npm run build`。
万象配套检查：`make all PYTEST_JOBS=4`，重点覆盖 `tests/integration/test_interaction_preferences.py` 和 `tests/unit/agents/test_interaction_preferences.py`。

自动化覆盖保存回读、角色隔离、越权拒绝、重启保留、忙碌拒绝、重载回滚及公共模型通道注入。真实模型已对四种风格进行对照复测，并检查本轮明确要求优先于长期偏好；真实对话和本地运行配置不随源码提交。微信实际入口仍需单独验收，自动化通道注入测试不能代替微信实际回复确认。

| 场景 | 同一问题在不同风格下检查什么 |
| --- | --- |
| 简短问答：“帮我解释一下机会成本，用两句话。” | 所有风格尊重本轮两句话要求，避免强行追问 |
| 情绪表达：“今天事情很多，我很累，暂时不想听建议。” | 倾听与共情，明确要求优先，不自动给行动清单 |
| 方案讨论：“我想每天学习两小时，但常常坚持不下来。” | 直接建议给可行下一步；探索型检视假设并最多问一个主要问题 |
| 事实纠正：“一年总是365天，对吗？” | 所有风格都纠错；不同意见的表达方式有差别，不迎合错误 |

在个人角色保存，在工作角色确认未继承；重新打开设置确认回读；客户端和微信分别发送上述问题，由用户确认风格差异。
真实盒子必须具备配套服务端代码。仅更新客户端会正确显示暂不支持，不能宣称已完成微信效果验收。

## 表达约束加强（2026-10-15，本地）

偏好枚举和存储版本不变，调整服务端受控说明：

- 简短：普通问题以2—4句、40—120字为表达目标；定义题通常80字以内，方案通常不超过200字、最多3点。先结论，少铺垫。安全、事实完整性和本轮明确要求优先，不修改 max_tokens。
- 倾听：用户仅表达感受时，回应后允许结束，不把共情作为分析原因、诊断心理或布置行动的开场白；主动问建议时仍正常回答。
- 主动建议：需要推进时提供一个可选的小步骤；不把下一步留到追问之后。纯定义、算术或明确拒绝建议时不硬塞行动。
- 探索：在方案与判断中比较有意义的取舍、检视一个关键假设；简单题仍直接回答。
- 记忆作为事实依据，不沿用历史答案的措辞和长度；默认不展示内部记忆路径。没有清空或修改历史和角色记忆。

规则由五项枚举组合产生，预设名称不会覆盖用户的微调值。
